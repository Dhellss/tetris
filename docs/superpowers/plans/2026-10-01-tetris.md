# Tetris + Spin Guide Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single-player, guideline-compliant Tetris that runs by opening `index.html`, plus a watchable animated guide that explains SRS wall kicks, floor kicks, and T-spins.

**Architecture:** A pure `engine/` layer (no canvas, no DOM, no event listeners) that takes a per-frame action set and returns state plus events, wrapped by a `ui/` layer that renders to one `<canvas>` and reflects events into DOM. The Spin Guide drives the same engine with scripted actions at reduced speed, so it can never teach a rule the game does not implement.

**Tech Stack:** Vanilla HTML/CSS/JavaScript. No framework, no bundler, no npm install. Scripts load as plain ordered `<script>` tags. Tests run two ways: `node tests/run.js` on the command line (node's built-in `vm`, no packages) and `tests/test.html` in a browser.

**Spec:** `docs/superpowers/specs/2026-10-01-tetris-design.md`

## Global Constraints

- No framework, no bundler, no npm install needed to play or to test.
- Must work from a `file://` URL: no ES modules, no `import`/`export`, no `fetch` of local files. All data is declared in JavaScript.
- Every file uses this exact module pattern so one source works in both the browser and node's `vm`:
  ```js
  (function (root) {
    'use strict';
    // ...
    root.Name = { /* public API */ };
  })(typeof window !== 'undefined' ? window : globalThis);
  ```
- `engine/` files must not reference `window`, `document`, `canvas`, `localStorage`, or any event API. The module pattern's `root` parameter is the only exception.
- Playfield is 10 columns x 40 rows with the bottom 20 visible.
- All timing is in milliseconds driven by the frame delta, never in frames.
- Rotation state names are the strings `'0'`, `'R'`, `'2'`, `'L'`.
- Kick table offsets are written `x` right-positive and `y` **up**-positive, exactly as in the spec. Conversion to board coordinates (y down) happens in exactly one place: `SRS.rotate`.
- Target 60fps on a modest laptop.
- Commit after every task.

## Review Focus

Five failure modes the spec implies but does not describe, most likely first. Each has a test added to the task that owns the code.

1. **Tab switch or window blur produces a huge frame delta.** A 30-second background tab hands the loop a 30000ms delta; unclamped, the piece falls through the stack and several locks resolve in one frame. Expected: delta clamped to 100ms per tick, and the game pauses itself on blur. *Test in Task 5 and Task 7.*
2. **Corrupt or missing `localStorage` values.** A hand-edited or half-written settings key must not stop the game from starting. Expected: any unparseable or out-of-range value falls back to its default, silently. *Test in Task 6.*
3. **A key held down across a pause, retry, or game over.** Without clearing repeat state, the piece keeps auto-shifting into the next game, or a held rotate fires at spawn. Expected: all repeat timers and pressed-key state reset whenever the game state changes. *Test in Task 6.*
4. **OS-level key repeat on non-movement keys.** Holding hard drop or rotate fires `keydown` dozens of times per second; the spec says these fire once per press. Expected: `event.repeat` is ignored, and the action latches until the key is released. *Test in Task 6.*
5. **A viewport too short for 20 rows, or a zero-size canvas.** Cell size derived from available height becomes 0 or negative, producing an invisible board or a divide-by-zero in hit math. Expected: cell size clamps to a minimum of 8px and the canvas never gets a dimension below 1. *Test in Task 7.*

  - `Pieces.boxSize(type)` -> `4` for `'I'`, else `3`

  - `Board.index(board, x, y)` -> `y * board.cols + x`
  - `Board.isOccupied(board, x, y)` -> `true` outside the left, right, or bottom edges; `false` above the top; otherwise whether that cell holds a piece type
  - `Board.collides(board, piece)` -> boolean
  - `Board.lock(board, piece)` -> mutates `grid`, returns `board`
  - `Board.clearLines(board)` -> `{rows:[indices, top first], count}`, mutates `grid`
  - `Board.isEmpty(board)` -> boolean
  - `Board.fromRows(rows)` -> board built from an array of 10-character strings, bottom-aligned, `'.'` empty and any other character filled with `'G'`

Create `tests/harness.js`:

```js
(function (root) {
  'use strict';

  const suites = [];
  let current = null;

  function describe(name, fn) {
    current = { name: name, tests: [] };
    suites.push(current);
    fn();
    current = null;
  }

  function it(name, fn) {
    if (!current) throw new Error('it() outside describe(): ' + name);
    current.tests.push({ name: name, fn: fn });
  }

  function assert(cond, msg) {
    if (!cond) throw new Error(msg || 'assertion failed');
  }

  function assertEqual(actual, expected, msg) {
    if (actual !== expected) {
      throw new Error((msg || 'not equal') + ' — expected ' + JSON.stringify(expected) + ', got ' + JSON.stringify(actual));
    }
  }

  function assertDeepEqual(actual, expected, msg) {
    const a = JSON.stringify(actual);
    const e = JSON.stringify(expected);
    if (a !== e) throw new Error((msg || 'not deep equal') + ' — expected ' + e + ', got ' + a);
  }

  // Reports to console (node) and, when present, to #results (browser).
  function run() {
    let passed = 0;
    const failures = [];
    const out = (typeof document !== 'undefined') ? document.getElementById('results') : null;

    function line(text, cls) {
      if (out) {
        const el = document.createElement('div');
        el.className = cls;
        el.textContent = text;
        out.appendChild(el);
      }
      console.log(text);
    }

    for (const suite of suites) {
      line(suite.name, 'suite');
      for (const test of suite.tests) {
        try {
          test.fn();
          passed++;
          line('  PASS  ' + test.name, 'pass');
        } catch (err) {
          failures.push({ suite: suite.name, test: test.name, err: err });
          line('  FAIL  ' + test.name + '\n        ' + err.message, 'fail');
        }
      }
    }

    line('\n' + passed + ' passed, ' + failures.length + ' failed', failures.length ? 'fail' : 'pass');
    return { passed: passed, failed: failures.length };
  }

  root.Harness = {
    describe: describe,
    it: it,
    assert: assert,
    assertEqual: assertEqual,
    assertDeepEqual: assertDeepEqual,
    run: run
  };
})(typeof window !== 'undefined' ? window : globalThis);
```

```js
(function (root) {
  'use strict';

  const STATES = ['0', 'R', '2', 'L'];

  // Box-relative cells, y down, origin at the box's top-left corner.
  // JLSTZ and O use a 3x3 box; I uses 4x4.
  const SHAPES = {
    I: {
      '0': [[0, 1], [1, 1], [2, 1], [3, 1]],
      'R': [[2, 0], [2, 1], [2, 2], [2, 3]],
      '2': [[0, 2], [1, 2], [2, 2], [3, 2]],
      'L': [[1, 0], [1, 1], [1, 2], [1, 3]]
    },
    J: {
      '0': [[0, 0], [0, 1], [1, 1], [2, 1]],
      'R': [[1, 0], [2, 0], [1, 1], [1, 2]],
      '2': [[0, 1], [1, 1], [2, 1], [2, 2]],
      'L': [[1, 0], [1, 1], [0, 2], [1, 2]]
    },
    L: {
      '0': [[2, 0], [0, 1], [1, 1], [2, 1]],
      'R': [[1, 0], [1, 1], [1, 2], [2, 2]],
      '2': [[0, 1], [1, 1], [2, 1], [0, 2]],
      'L': [[0, 0], [1, 0], [1, 1], [1, 2]]
    },
    O: {
      '0': [[1, 0], [2, 0], [1, 1], [2, 1]],
      'R': [[1, 0], [2, 0], [1, 1], [2, 1]],
      '2': [[1, 0], [2, 0], [1, 1], [2, 1]],
      'L': [[1, 0], [2, 0], [1, 1], [2, 1]]
    },
    S: {
      '0': [[1, 0], [2, 0], [0, 1], [1, 1]],
      'R': [[1, 0], [1, 1], [2, 1], [2, 2]],
      '2': [[1, 1], [2, 1], [0, 2], [1, 2]],
      'L': [[0, 0], [0, 1], [1, 1], [1, 2]]
    },
    T: {
      '0': [[1, 0], [0, 1], [1, 1], [2, 1]],
      'R': [[1, 0], [1, 1], [2, 1], [1, 2]],
      '2': [[0, 1], [1, 1], [2, 1], [1, 2]],
      'L': [[1, 0], [0, 1], [1, 1], [1, 2]]
    },
    Z: {
      '0': [[0, 0], [1, 0], [1, 1], [2, 1]],
      'R': [[2, 0], [1, 1], [2, 1], [1, 2]],
      '2': [[0, 1], [1, 1], [1, 2], [2, 2]],
      'L': [[1, 0], [0, 1], [1, 1], [0, 2]]
    }
  };

  // Precompute as {x, y} objects so callers never mutate the source arrays.
  const CELLS = {};
  for (const type of Object.keys(SHAPES)) {
    CELLS[type] = {};
    for (const state of STATES) {
      CELLS[type][state] = SHAPES[type][state].map(function (pair) {
        return { x: pair[0], y: pair[1] };
      });
    }
  }

  function boxSize(type) {
    return type === 'I' ? 4 : 3;
  }

  function cells(type, state) {
    const byState = CELLS[type];
    if (!byState) throw new Error('unknown piece type: ' + type);
    const list = byState[state];
    if (!list) throw new Error('unknown rotation state: ' + state);
    return list;
  }

  // Spawn so the box sits in columns 3..5 (3..6 for I), with its top row
  // two rows above the visible field. Rows 18 and 19 of a 40-row grid are
  // the last two buffer rows.
  function spawn(type) {
    return { type: type, state: '0', x: 3, y: 18 };
  }

  root.Pieces = {
    TYPES: ['I', 'J', 'L', 'O', 'S', 'T', 'Z'],
    STATES: STATES,
    COLORS: {
      I: '#31c7ef',
      J: '#5a65ad',
      L: '#ef7921',
      O: '#f7d308',
      S: '#42b642',
      T: '#ad4d9c',
      Z: '#ef2029'
    },
    boxSize: boxSize,
    cells: cells,
    spawn: spawn
  };
})(typeof window !== 'undefined' ? window : globalThis);
```

- [ ] **Step 7: Implement board.js**

Create `engine/board.js`:

```js
(function (root) {
  'use strict';

  const COLS = 10;
  const ROWS = 40;
  const VISIBLE_ROWS = 20;

  function create() {
    return {
      cols: COLS,
      rows: ROWS,
      visibleRows: VISIBLE_ROWS,
      grid: new Array(COLS * ROWS).fill(null)
    };
  }

  function index(board, x, y) {
    return y * board.cols + x;
  }

  // Outside the sides and below the floor counts as occupied so collision
  // needs no separate bounds check. Above the grid is open sky.
  function isOccupied(board, x, y) {
    if (x < 0 || x >= board.cols) return true;
    if (y >= board.rows) return true;
    if (y < 0) return false;
    return board.grid[index(board, x, y)] !== null;
  }

  function collides(board, piece) {
    const cells = Pieces.cells(piece.type, piece.state);
    for (let i = 0; i < cells.length; i++) {
      if (isOccupied(board, piece.x + cells[i].x, piece.y + cells[i].y)) return true;
    }
    return false;
  }

  function lock(board, piece) {
    const cells = Pieces.cells(piece.type, piece.state);
    for (let i = 0; i < cells.length; i++) {
      const x = piece.x + cells[i].x;
      const y = piece.y + cells[i].y;
      if (y >= 0 && y < board.rows && x >= 0 && x < board.cols) {
        board.grid[index(board, x, y)] = piece.type;
      }
    }
    return board;
  }

  function isRowFull(board, y) {
    for (let x = 0; x < board.cols; x++) {
      if (board.grid[index(board, x, y)] === null) return false;
    }
    return true;
  }

  // Removes every full row and lets the rows above fall. Returns the
  // cleared row indices, top first, so the renderer can flash them.
  function clearLines(board) {
    const cleared = [];
    for (let y = 0; y < board.rows; y++) {
      if (isRowFull(board, y)) cleared.push(y);
    }
    if (cleared.length === 0) return { rows: cleared, count: 0 };

    const kept = [];
    for (let y = 0; y < board.rows; y++) {
      if (cleared.indexOf(y) === -1) {
        kept.push(board.grid.slice(y * board.cols, (y + 1) * board.cols));
      }
    }
    while (kept.length < board.rows) {
      kept.unshift(new Array(board.cols).fill(null));
    }

    const next = [];
    for (let i = 0; i < kept.length; i++) {
      for (let x = 0; x < board.cols; x++) next.push(kept[i][x]);
    }
    board.grid = next;

    return { rows: cleared, count: cleared.length };
  }

  function isEmpty(board) {
    for (let i = 0; i < board.grid.length; i++) {
      if (board.grid[i] !== null) return false;
    }
```

```js
(function (root) {
  'use strict';

  // Small, fast, fully deterministic PRNG. Math.random cannot be seeded,
  // and the guide lessons and tests both need a fixed piece order.
  function mulberry32(seed) {
    let a = seed >>> 0;
    return function () {
      a = (a + 0x6D2B79F5) >>> 0;
      let t = a;
      t = Math.imul(t ^ (t >>> 15), t | 1);
      t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
      return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
    };
  }

  function create(seed) {
    const random = mulberry32(typeof seed === 'number' ? seed : 0);
    let queue = [];

    function refill() {
      const bag = Pieces.TYPES.slice();
      // Fisher-Yates, drawing from the seeded source.
      for (let i = bag.length - 1; i > 0; i--) {
        const j = Math.floor(random() * (i + 1));
        const tmp = bag[i];
        bag[i] = bag[j];
        bag[j] = tmp;
      }
      queue = queue.concat(bag);
    }

    function ensure(count) {
      while (queue.length < count) refill();
    }

    return {
      next: function () {
        ensure(1);
        return queue.shift();
      },
      peek: function (count) {
        ensure(count);
        return queue.slice(0, count);
      }
    };
  }

  root.Randomizer = {
    create: create,
    mulberry32: mulberry32
  };
})(typeof window !== 'undefined' ? window : globalThis);
```

```js
(function (root) {
  'use strict';

  const ORDER = ['0', 'R', '2', 'L'];

  // Offsets are [x, y] with y UP-positive, matching every published SRS
  // reference. rotate() is the only place that flips y for board use.
  const KICKS_JLSTZ = {
    '0>R': [[0, 0], [-1, 0], [-1, 1], [0, -2], [-1, -2]],
    'R>0': [[0, 0], [1, 0], [1, -1], [0, 2], [1, 2]],
    'R>2': [[0, 0], [1, 0], [1, -1], [0, 2], [1, 2]],
    '2>R': [[0, 0], [-1, 0], [-1, 1], [0, -2], [-1, -2]],
    '2>L': [[0, 0], [1, 0], [1, 1], [0, -2], [1, -2]],
    'L>2': [[0, 0], [-1, 0], [-1, -1], [0, 2], [-1, 2]],
    'L>0': [[0, 0], [-1, 0], [-1, -1], [0, 2], [-1, 2]],
    '0>L': [[0, 0], [1, 0], [1, 1], [0, -2], [1, -2]]
  };

  const KICKS_I = {
    '0>R': [[0, 0], [-2, 0], [1, 0], [-2, -1], [1, 2]],
    'R>0': [[0, 0], [2, 0], [-1, 0], [2, 1], [-1, -2]],
    'R>2': [[0, 0], [-1, 0], [2, 0], [-1, 2], [2, -1]],
    '2>R': [[0, 0], [1, 0], [-2, 0], [1, -2], [-2, 1]],
    '2>L': [[0, 0], [2, 0], [-1, 0], [2, 1], [-1, -2]],
    'L>2': [[0, 0], [-2, 0], [1, 0], [-2, -1], [1, 2]],
    'L>0': [[0, 0], [1, 0], [-2, 0], [1, -2], [-2, 1]],
    '0>L': [[0, 0], [-1, 0], [2, 0], [-1, 2], [2, -1]]
  };

  // Up before down: a 180 is usually performed resting on a surface, so
  // the clearance it needs is above the piece.
  const HALF = [[0, 0], [0, 1], [0, -1], [1, 0], [-1, 0]];
  const KICKS_180 = {
    '0>2': HALF,
    'R>L': HALF,
    '2>0': HALF,
    'L>R': HALF
  };

  function nextState(state, dir) {
    const from = ORDER.indexOf(state);
    if (from === -1) throw new Error('unknown rotation state: ' + state);
    const steps = dir === 2 ? 2 : (dir > 0 ? 1 : 3);
    return ORDER[(from + steps) % 4];
  }

  function table(type, from, to) {
    if (type === 'O') return null;
    const key = from + '>' + to;
    if (KICKS_180[key]) return KICKS_180[key];
    return type === 'I' ? KICKS_I[key] : KICKS_JLSTZ[key];
  }

  function fits(piece, isOccupied) {
    const cells = Pieces.cells(piece.type, piece.state);
    for (let i = 0; i < cells.length; i++) {
      if (isOccupied(piece.x + cells[i].x, piece.y + cells[i].y)) return false;
    }
    return true;
  }

  function rotate(piece, dir, isOccupied) {
    const to = nextState(piece.state, dir);
    const offsets = table(piece.type, piece.state, to);

    if (!offsets) {
      // O: the cells are identical in every state, so the state label
      // changes and nothing moves.
      const spun = { type: piece.type, state: to, x: piece.x, y: piece.y };
      return fits(spun, isOccupied) ? { piece: spun, kickIndex: 0 } : null;
    }

    for (let i = 0; i < offsets.length; i++) {
      const candidate = {
        type: piece.type,
        state: to,
        x: piece.x + offsets[i][0],
        y: piece.y - offsets[i][1]
      };
      if (fits(candidate, isOccupied)) return { piece: candidate, kickIndex: i };
    }
    return null;
  }

  // The two cells adjacent to the T's pointing edge, as [dx, dy] from the
  // T's centre in board coordinates.
  const FRONT_CORNERS = {
    '0': [[-1, -1], [1, -1]],
    'R': [[1, -1], [1, 1]],
    '2': [[-1, 1], [1, 1]],
    'L': [[-1, -1], [-1, 1]]
  };
  const ALL_CORNERS = [[-1, -1], [1, -1], [-1, 1], [1, 1]];

  function classifySpin(piece, kickIndex, isOccupied) {
    if (piece.type !== 'T') return 'none';

    // The T's centre is box cell (1,1).
    const cx = piece.x + 1;
    const cy = piece.y + 1;

    let occupied = 0;
    for (let i = 0; i < ALL_CORNERS.length; i++) {
      if (isOccupied(cx + ALL_CORNERS[i][0], cy + ALL_CORNERS[i][1])) occupied++;
    }
    if (occupied < 3) return 'none';

    const front = FRONT_CORNERS[piece.state];
    let frontFilled = 0;
    for (let i = 0; i < front.length; i++) {
      if (isOccupied(cx + front[i][0], cy + front[i][1])) frontFilled++;
    }

    if (frontFilled === 2) return 'tspin';
    // The fifth offset is the deep kick that makes a T-spin Triple
    // possible; a mini reached that way counts as the real thing.
    return kickIndex === 4 ? 'tspin' : 'mini';
  }

  root.SRS = {
    KICKS_JLSTZ: KICKS_JLSTZ,
    KICKS_I: KICKS_I,
    KICKS_180: KICKS_180,
    nextState: nextState,
    table: table,
    rotate: rotate,
    classifySpin: classifySpin
  };
})(typeof window !== 'undefined' ? window : globalThis);
```

```js
(function (root) {
  'use strict';

  const SOFT_DROP_MS = 50;        // 20 cells per second
  const MAX_GRAVITY_LEVEL = 20;   // the curve goes imaginary past level 115

  const CLEAR_POINTS = {
    'none': 0,
    'single': 100,
    'double': 300,
    'triple': 500,
    'tetris': 800,
    'tspin': 400,
    'tspin-single': 800,
    'tspin-double': 1200,
    'tspin-triple': 1600,
    'mini': 100,
    'mini-single': 200,
    'mini-double': 400
  };

  const PERFECT_CLEAR_POINTS = { 1: 800, 2: 1200, 3: 1800, 4: 2000 };

  const PLAIN_NAMES = ['none', 'single', 'double', 'triple', 'tetris'];

  function create() {
    return { score: 0, lines: 0, level: 1, chain: 0, b2b: false };
  }

  function kindFor(lines, spin) {
    if (spin === 'tspin' || spin === 'mini') {
      const prefix = spin === 'tspin' ? 'tspin' : 'mini';
      if (lines === 0) return prefix;
      return prefix + '-' + PLAIN_NAMES[lines];
    }
    return PLAIN_NAMES[lines] || 'none';
  }

  function levelForLines(lines) {
    return 1 + Math.floor(lines / 10);
  }

  // Guideline curve: seconds per cell at level n.
  function gravityMs(level) {
    const n = Math.max(1, Math.min(level, MAX_GRAVITY_LEVEL));
    return Math.pow(0.8 - (n - 1) * 0.007, n - 1) * 1000;
  }

  // A clear is "difficult" — and so eligible for back-to-back — when it is
  // a tetris or any T-spin that cleared at least one line.
  function isDifficult(lines, spin) {
    if (lines === 0) return false;
    return lines === 4 || spin === 'tspin' || spin === 'mini';
  }

  function applyLock(state, event) {
    const lines = event.lines || 0;
    const spin = event.spin || 'none';
    const kind = kindFor(lines, spin);
    const difficult = isDifficult(lines, spin);

    // Back-to-back applies when the previous difficult clear is still
    // standing. A dry lock breaks the combo but leaves it alone.
    const b2b = difficult && state.b2b === true;

    let points = CLEAR_POINTS[kind] || 0;
    if (b2b) points = Math.floor(points * 1.5);

    if (lines > 0) {
      state.chain += 1;
      if (state.chain >= 2) points += 50 * (state.chain - 1);
    } else {
      state.chain = 0;
    }

    if (event.perfectClear && PERFECT_CLEAR_POINTS[lines]) {
      points += PERFECT_CLEAR_POINTS[lines];
    }

    points = points * state.level;

    if (difficult) {
      state.b2b = true;
    } else if (lines > 0) {
      state.b2b = false;
    }

    const levelBefore = state.level;
    state.lines += lines;
    state.level = levelForLines(state.lines);
    state.score += points;

    return {
      points: points,
      kind: kind,
      b2b: b2b,
      chain: state.chain,
      leveledUp: state.level > levelBefore
    };
  }

  function addDropPoints(state, cells, isHard) {
    const points = cells * (isHard ? 2 : 1);
    state.score += points;
    return points;
  }

  root.Scoring = {
    SOFT_DROP_MS: SOFT_DROP_MS,
    MAX_GRAVITY_LEVEL: MAX_GRAVITY_LEVEL,
    CLEAR_POINTS: CLEAR_POINTS,
    PERFECT_CLEAR_POINTS: PERFECT_CLEAR_POINTS,
    create: create,
    kindFor: kindFor,
    levelForLines: levelForLines,
    gravityMs: gravityMs,
    isDifficult: isDifficult,
    applyLock: applyLock,
    addDropPoints: addDropPoints
  };
})(typeof window !== 'undefined' ? window : globalThis);
```

Note on the combo bonus: the spec writes it as `50 * comboCount * level`, and the `* level` here comes from the single `points * state.level` line that covers everything. Do not multiply twice.

The piece lifecycle: spawn, gravity, lock delay with its reset budget, hold, hard drop, line clear, and both top-out conditions. This task also owns the frame-delta clamp from Review Focus item 1.

- Produces:
  - `Game.MAX_TICK_MS` -> `100`
  - `Game.DEFAULTS` -> `{mode:'marathon', seed:0, lockDelayMs:500, maxResets:15, queueSize:5, sprintLines:40, softDropMs:50}`
  - `Game.create(options)` -> game state. `options` also accepts `board` (a prebuilt `Board`, for lessons and tests) and `pieces` (an array of type strings dealt before the bag takes over).
  - `Game.tick(g, dtMs, actions)` -> array of event objects; mutates `g`. `actions` is `{left, right, softDrop, hardDrop, rotateCW, rotateCCW, rotate180, hold}`, each a boolean meaning "do this once now", plus an optional `moveCells` integer (default 1) giving how many cells a horizontal pulse may travel.   - `Game.isGrounded(g)` -> boolean

**Spin rule made explicit:** a T-spin requires the rotation to be the last thing that moved the piece. Any successful horizontal move, and any downward movement of one or more cells from gravity, soft drop, or hard drop, clears the flag. A hard drop that moves zero cells — the piece was already resting — leaves it intact, which is what makes "rotate into the slot, then slam" work.

```js
(function (root) {
  'use strict';

  const MAX_TICK_MS = 100;

  const DEFAULTS = {
    mode: 'marathon',
    seed: 0,
    lockDelayMs: 500,
    maxResets: 15,
    queueSize: 5,
    sprintLines: 40,
    softDropMs: 50      // 20 cells per second; the settings screen can lower this
  };

  function occupancy(board) {
    return function (x, y) { return Board.isOccupied(board, x, y); };
  }

  function copyPiece(piece) {
    return { type: piece.type, state: piece.state, x: piece.x, y: piece.y };
  }

  // A dealer that hands out a scripted list first, then falls back to the
  // seeded bag. Lessons and tests need a known opening; play does not.
  function createDealer(seed, scripted) {
    const bag = Randomizer.create(seed);
    const pending = scripted ? scripted.slice() : [];
    return function () {
      return pending.length > 0 ? pending.shift() : bag.next();
    };
  }

  function create(options) {
    const opts = {};
    for (const key of Object.keys(DEFAULTS)) opts[key] = DEFAULTS[key];
    if (options) {
      for (const key of Object.keys(options)) opts[key] = options[key];
    }

    const g = {
      opts: opts,
      mode: opts.mode,
      board: opts.board || Board.create(),
      deal: createDealer(opts.seed, opts.pieces),
      queue: [],
      piece: null,
      hold: null,
      canHold: true,
      scoring: Scoring.create(),
      status: 'playing',
      gravityMs: 0,
      lockMs: 0,
      resets: 0,
      grounded: false,
      lastKickIndex: 0,
      rotatedLast: false,
      timeMs: 0,
      piecesPlaced: 0
    };

    refillQueue(g);
    spawn(g, g.queue.shift(), []);
    return g;
  }

  function refillQueue(g) {
    while (g.queue.length < g.opts.queueSize) g.queue.push(g.deal());
  }

  function spawn(g, type, events) {
    const piece = Pieces.spawn(type);
    g.piece = piece;
    g.gravityMs = 0;
    g.lockMs = 0;
    g.resets = 0;
    g.grounded = false;
    g.rotatedLast = false;
    g.lastKickIndex = 0;
    refillQueue(g);

    if (Board.collides(g.board, piece)) {
      g.status = 'over';
      events.push({ type: 'gameover', reason: 'blockout' });
      return false;
    }
    events.push({ type: 'spawn', piece: copyPiece(piece) });
    return true;
  }

  function isGrounded(g) {
    if (!g.piece) return false;
    return Board.collides(g.board, {
      type: g.piece.type,
      state: g.piece.state,
      x: g.piece.x,
      y: g.piece.y + 1
    });
  }

  function ghostY(g) {
    if (!g.piece) return null;
    let y = g.piece.y;
    while (!Board.collides(g.board, {
      type: g.piece.type, state: g.piece.state, x: g.piece.x, y: y + 1
    })) y++;
    return y;
  }

  function tryMove(g, dx, dy) {
    const moved = {
      type: g.piece.type, state: g.piece.state,
      x: g.piece.x + dx, y: g.piece.y + dy
    };
    if (Board.collides(g.board, moved)) return false;
    g.piece = moved;
    return true;
  }

  // Called after any successful move or rotation. Spends one unit of the
  // reset budget while grounded; airborne, the timer is simply irrelevant.
  function noteAction(g, wasRotation) {
    g.rotatedLast = wasRotation;
    if (isGrounded(g)) {
      if (g.resets < g.opts.maxResets) {
        g.resets += 1;
        g.lockMs = 0;
      }
    } else {
      g.lockMs = 0;
    }
  }

  function doHold(g, events) {
    if (!g.canHold || !g.piece) return;
    const held = g.piece.type;
    const incoming = g.hold === null ? g.queue.shift() : g.hold;
    g.hold = held;
    events.push({ type: 'hold', held: held, incoming: incoming });
    spawn(g, incoming, events);
    g.canHold = false;
  }

  function lockPiece(g, events) {
    const spin = g.rotatedLast
      ? SRS.classifySpin(g.piece, g.lastKickIndex, occupancy(g.board))
      : 'none';

    const cells = Pieces.cells(g.piece.type, g.piece.state);
    const visibleTop = g.board.rows - g.board.visibleRows;
    let lockedOut = true;
    for (let i = 0; i < cells.length; i++) {
      if (g.piece.y + cells[i].y >= visibleTop) { lockedOut = false; break; }
    }

    const placed = copyPiece(g.piece);
    Board.lock(g.board, g.piece);
    g.piecesPlaced += 1;

    const cleared = Board.clearLines(g.board);
    const perfectClear = cleared.count > 0 && Board.isEmpty(g.board);
    const result = Scoring.applyLock(g.scoring, {
      lines: cleared.count,
      spin: spin,
      perfectClear: perfectClear
    });

    events.push({
      type: 'lock',
      piece: placed,
      spin: spin,
      lines: cleared.count,
      rows: cleared.rows,
      perfectClear: perfectClear,
      points: result.points,
      b2b: result.b2b,
      chain: result.chain,
      kind: result.kind
    });
    if (result.leveledUp) events.push({ type: 'levelup', level: g.scoring.level });

    g.piece = null;
    g.canHold = true;

    if (lockedOut) {
      g.status = 'over';
      events.push({ type: 'gameover', reason: 'lockout' });
      return;
    }
    if (g.mode === 'sprint' && g.scoring.lines >= g.opts.sprintLines) {
      g.status = 'won';
      events.push({ type: 'win', timeMs: g.timeMs, lines: g.scoring.lines });
      return;
    }
    spawn(g, g.queue.shift(), events);
  }

  function tick(g, dtMs, actions) {
    const events = [];
    if (g.status !== 'playing') return events;

    // A backgrounded tab can hand over tens of seconds at once. Without
    // this clamp the piece teleports through the stack.
    const dt = Math.max(0, Math.min(dtMs || 0, MAX_TICK_MS));
    g.timeMs += dt;

    const a = actions || {};

    if (a.hold) doHold(g, events);
    if (g.status !== 'playing' || !g.piece) return events;

    let dir = 0;
    if (a.rotateCW) dir = 1;
    else if (a.rotateCCW) dir = -1;
    else if (a.rotate180) dir = 2;
    if (dir !== 0) {
      const spun = SRS.rotate(g.piece, dir, occupancy(g.board));
      if (spun) {
        g.piece = spun.piece;
        g.lastKickIndex = spun.kickIndex;
        noteAction(g, true);
        events.push({ type: 'rotate', kickIndex: spun.kickIndex, state: g.piece.state });
      }
    }

    // One cell per pulse by default. Input passes a larger moveCells when
    // ARR is 0, which is what makes a held key slide to the wall in one
    // frame the way modern clients do.
    let dx = 0;
    if (a.left) dx -= 1;
    if (a.right) dx += 1;
    if (dx !== 0) {
      const steps = Math.max(1, a.moveCells || 1);
      let moved = 0;
      while (moved < steps && tryMove(g, dx, 0)) moved += 1;
      if (moved > 0) {
        noteAction(g, false);
        events.push({ type: 'move', dx: dx * moved });
      }
    }

    if (a.hardDrop) {
      const target = ghostY(g);
      const distance = target - g.piece.y;
      if (distance > 0) {
        g.piece = { type: g.piece.type, state: g.piece.state, x: g.piece.x, y: target };
        Scoring.addDropPoints(g.scoring, distance, true);
        g.rotatedLast = false;
      }
      events.push({ type: 'harddrop', cells: distance });
      lockPiece(g, events);
      return events;
    }

    const level = g.mode === 'sprint' ? 1 : g.scoring.level;
    let intervalMs = Scoring.gravityMs(level);
    if (a.softDrop) intervalMs = Math.min(intervalMs, g.opts.softDropMs);

    g.gravityMs += dt;
    let fell = 0;
    while (g.gravityMs >= intervalMs) {
      g.gravityMs -= intervalMs;
      if (tryMove(g, 0, 1)) {
        fell += 1;
      } else {
        g.gravityMs = 0;
        break;
      }
    }
    if (fell > 0) {
      g.rotatedLast = false;
      g.lockMs = 0;
      if (a.softDrop) Scoring.addDropPoints(g.scoring, fell, false);
      events.push({ type: 'fall', cells: fell });
    }

    g.grounded = isGrounded(g);
    if (g.grounded) {
      g.lockMs += dt;
      if (g.lockMs >= g.opts.lockDelayMs) lockPiece(g, events);
    } else {
      g.lockMs = 0;
    }

    return events;
  }

  root.Game = {
    MAX_TICK_MS: MAX_TICK_MS,
    DEFAULTS: DEFAULTS,
    create: create,
    tick: tick,
    ghostY: ghostY,
    isGrounded: isGrounded
  };
})(typeof window !== 'undefined' ? window : globalThis);
```

- Create: `ui/input.js`, `tests/ui.test.js`
- Modify: `tests/run.js` is already set up to load both

**Interfaces:**
- Consumes: nothing from the engine
- Produces:
  - `Input.ACTIONS` -> `['left','right','softDrop','hardDrop','rotateCW','rotateCCW','rotate180','hold','pause','retry']`
  - `Input.ONE_SHOT` -> `['hardDrop','rotateCW','rotateCCW','rotate180','hold','pause','retry']`
  - `Input.DEFAULT_BINDINGS` -> a map of `KeyboardEvent.code` to action name
  - `Input.DEFAULT_HANDLING` -> `{dasMs:100, arrMs:0, softDropFactor:20}`
  - `Input.STORAGE_KEY` -> `'tetris.settings.v1'`
  - `Input.createState(settings)` -> input state
  - `Input.press(state, code)` / `Input.release(state, code)` -> void; unknown codes are ignored
  - `Input.poll(state, dtMs)` -> `{left, right, softDrop, hardDrop, rotateCW, rotateCCW, rotate180, hold, pause, retry, moveCells}`; one-shots are consumed
  - `Input.reset(state)` -> clears every held key, queued one-shot, and repeat timer
  - `Input.sanitizeHandling(raw)` -> a valid handling object, clamping or replacing bad values
  - `Input.sanitizeBindings(raw)` -> a valid bindings map, dropping unknown actions, falling back to the defaults when nothing usable survives
  - `Input.loadSettings(storage)` -> `{bindings, handling}`; never throws
  - `Input.saveSettings(storage, settings)` -> boolean success
  - `Input.attach(state, target)` -> a detach function; ignores `event.repeat`

Bindings key on `event.code`, not `event.key`, so the controls do not move with the keyboard layout and rebinding stores something stable.

```js
  const STORAGE_KEY = 'tetris.settings.v1';

  // Wide enough to cross the board from either edge in one frame.
  const SLIDE_CELLS = 12;

  const LIMITS = {
    dasMs: { min: 0, max: 500 },
    arrMs: { min: 0, max: 200 },
    softDropFactor: { min: 1, max: 60 }
  };

  function isOneShot(action) {
    return ONE_SHOT.indexOf(action) !== -1;
  }

  function copy(source) {
    const out = {};
    for (const key of Object.keys(source)) out[key] = source[key];
    return out;
  }

  function sanitizeHandling(raw) {
    const out = copy(DEFAULT_HANDLING);
    if (!raw || typeof raw !== 'object') return out;
    for (const key of Object.keys(LIMITS)) {
      const value = raw[key];
      if (typeof value !== 'number' || !isFinite(value)) continue;
      out[key] = Math.max(LIMITS[key].min, Math.min(value, LIMITS[key].max));
    }
    return out;
  }

  function sanitizeBindings(raw) {
    if (!raw || typeof raw !== 'object') return copy(DEFAULT_BINDINGS);
    const out = {};
    let kept = 0;
    for (const code of Object.keys(raw)) {
      const action = raw[code];
      if (typeof action === 'string' && ACTIONS.indexOf(action) !== -1) {
        out[code] = action;
        kept += 1;
      }
    }
    // An empty or wholly invalid map would leave the game unplayable.
    return kept > 0 ? out : copy(DEFAULT_BINDINGS);
  }

  // Storage can be absent, throw outright, or hold anything at all. None
  // of that is a reason for the game not to start.
  function loadSettings(storage) {
    const fallback = { bindings: copy(DEFAULT_BINDINGS), handling: copy(DEFAULT_HANDLING) };
    if (!storage) return fallback;

    let raw = null;
    try {
      raw = storage.getItem(STORAGE_KEY);
    } catch (err) {
      return fallback;
    }
    if (!raw) return fallback;

    let parsed = null;
    try {
      parsed = JSON.parse(raw);
    } catch (err) {
      return fallback;
    }
    if (!parsed || typeof parsed !== 'object' || Array.isArray(parsed)) return fallback;

    return {
      bindings: sanitizeBindings(parsed.bindings),
      handling: sanitizeHandling(parsed.handling)
    };
  }

  function saveSettings(storage, settings) {
    if (!storage) return false;
    try {
      storage.setItem(STORAGE_KEY, JSON.stringify({
        bindings: sanitizeBindings(settings && settings.bindings),
        handling: sanitizeHandling(settings && settings.handling)
      }));
      return true;
    } catch (err) {
      return false;
    }
  }

  function createState(settings) {
    const resolved = settings || {};
    return {
      bindings: sanitizeBindings(resolved.bindings || DEFAULT_BINDINGS),
      handling: sanitizeHandling(resolved.handling || DEFAULT_HANDLING),
      held: {},          // action -> true while the key is down
      queued: {},        // one-shot action -> waiting to be polled
      direction: 0,      // -1 left, +1 right, 0 neither
      dirStack: [],      // held directions, most recent last
      repeatMs: 0,
      repeating: false,
      tapPending: false
    };
  }

  function reset(state) {
    state.held = {};
    state.queued = {};
    state.direction = 0;
    state.dirStack = [];
    state.repeatMs = 0;
    state.repeating = false;
    state.tapPending = false;
  }

  function applyDirection(state) {
    const stack = state.dirStack;
    const next = stack.length > 0 ? stack[stack.length - 1] : 0;
    if (next !== state.direction) {
      state.direction = next;
      // A new direction always starts from a fresh tap and a fresh DAS.
      state.repeatMs = 0;
      state.repeating = false;
      state.tapPending = next !== 0;
    }
  }

  function press(state, code) {
    const action = state.bindings[code];
    if (!action) return;
    if (state.held[action] === true) return;   // OS key repeat
    state.held[action] = true;

    if (isOneShot(action)) {
      state.queued[action] = true;
      return;
    }
    if (action === 'left' || action === 'right') {
      const dir = action === 'left' ? -1 : 1;
      const at = state.dirStack.indexOf(dir);
      if (at !== -1) state.dirStack.splice(at, 1);
      state.dirStack.push(dir);
      applyDirection(state);
    }
  }

  function release(state, code) {
    const action = state.bindings[code];
    if (!action) return;
    state.held[action] = false;

    if (action === 'left' || action === 'right') {
      const dir = action === 'left' ? -1 : 1;
      const at = state.dirStack.indexOf(dir);
      if (at !== -1) state.dirStack.splice(at, 1);
      applyDirection(state);
    }
  }

  function poll(state, dtMs) {
    const dt = Math.max(0, dtMs || 0);
    const actions = {};
    for (const action of ACTIONS) actions[action] = false;
    actions.moveCells = 1;

    for (const action of ONE_SHOT) {
      if (state.queued[action]) {
        actions[action] = true;
        state.queued[action] = false;
      }
    }

    actions.softDrop = state.held.softDrop === true;

    if (state.direction !== 0) {
      let move = false;

      if (state.tapPending) {
        state.tapPending = false;
        move = true;
        actions.moveCells = 1;
      } else {
        state.repeatMs += dt;
        if (!state.repeating) {
          if (state.repeatMs >= state.handling.dasMs) {
            state.repeating = true;
            state.repeatMs -= state.handling.dasMs;
            move = true;
            actions.moveCells = state.handling.arrMs === 0 ? SLIDE_CELLS : 1;
          }
        } else if (state.handling.arrMs === 0) {
          move = true;
          actions.moveCells = SLIDE_CELLS;
        } else {
          while (state.repeatMs >= state.handling.arrMs) {
            state.repeatMs -= state.handling.arrMs;
            move = true;
          }
          actions.moveCells = 1;
        }
      }

      if (move) {
        if (state.direction < 0) actions.left = true;
        else actions.right = true;
      }
    }

    return actions;
  }

  // The only part that needs a browser. Returns a detach function.
  function attach(state, target) {
    const node = target || root;

    function onKeyDown(event) {
      if (event.repeat) return;          // OS key repeat is not a new press
      if (!state.bindings[event.code]) return;
      event.preventDefault();            // stop Space and arrows scrolling the page
      press(state, event.code);
    }

    function onKeyUp(event) {
      if (!state.bindings[event.code]) return;
      event.preventDefault();
      release(state, event.code);
    }

    function onBlur() {
      reset(state);                      // keys cannot be seen going up
    }

    node.addEventListener('keydown', onKeyDown);
    node.addEventListener('keyup', onKeyUp);
    node.addEventListener('blur', onBlur);

    return function detach() {
      node.removeEventListener('keydown', onKeyDown);
      node.removeEventListener('keyup', onKeyUp);
      node.removeEventListener('blur', onBlur);
    };
  }

  root.Input = {
    ACTIONS: ACTIONS,
    ONE_SHOT: ONE_SHOT,
    DEFAULT_BINDINGS: DEFAULT_BINDINGS,
    DEFAULT_HANDLING: DEFAULT_HANDLING,
    STORAGE_KEY: STORAGE_KEY,
    SLIDE_CELLS: SLIDE_CELLS,
    sanitizeHandling: sanitizeHandling,
    sanitizeBindings: sanitizeBindings,
    loadSettings: loadSettings,
    saveSettings: saveSettings,
    createState: createState,
    reset: reset,
    press: press,
    release: release,
    poll: poll,
    attach: attach
  };
})(typeof window !== 'undefined' ? window : globalThis);
```

```js
(function (root) {
  'use strict';

  const MIN_CELL = 8;
  const PAD = 12;
  const GAP = 10;
  const PANEL_CELLS = 5;      // wide enough for a 4-cell piece plus margin
  const VISIBLE_ROWS = 20;
  const COLS = 10;

  const COLORS = {
    background: '#0e0f15',
    panel: '#15171f',
    grid: '#1e2130',
    border: '#2a2e42',
    garbage: '#555b70',
    ghost: 'rgba(215, 217, 224, 0.22)',
    text: '#d7d9e0'
  };

  function finiteOr(value, fallback) {
    const n = Number(value);
    return isFinite(n) ? n : fallback;
  }

  // Derived entirely from the viewport so the board never outgrows the
  // screen, and never collapses to nothing on a tiny or unmeasured one.
  function layout(viewportWidth, viewportHeight) {
    const viewW = Math.max(0, finiteOr(viewportWidth, 0));
    const viewH = Math.max(0, finiteOr(viewportHeight, 0));

    const columnsNeeded = COLS + PANEL_CELLS * 2;
    const byHeight = Math.floor((viewH - PAD * 2) / VISIBLE_ROWS);
    const byWidth = Math.floor((viewW - PAD * 2 - GAP * 2) / columnsNeeded);
    const cell = Math.max(MIN_CELL, Math.min(byHeight, byWidth));

    const boardW = cell * COLS;
    const boardH = cell * VISIBLE_ROWS;
    const panelW = cell * PANEL_CELLS;
    const holdX = PAD;
    const boardX = holdX + panelW + GAP;
    const nextX = boardX + boardW + GAP;

    return {
      cell: cell,
      boardW: boardW,
      boardH: boardH,
      panelW: panelW,
      gap: GAP,
      pad: PAD,
      holdX: holdX,
      boardX: boardX,
      nextX: nextX,
      totalW: Math.max(1, nextX + panelW + PAD),
      totalH: Math.max(1, boardH + PAD * 2)
    };
  }

  function roundRect(ctx, x, y, w, h, r) {
    const radius = Math.min(r, w / 2, h / 2);
    ctx.beginPath();
    ctx.moveTo(x + radius, y);
    ctx.arcTo(x + w, y, x + w, y + h, radius);
    ctx.arcTo(x + w, y + h, x, y + h, radius);
    ctx.arcTo(x, y + h, x, y, radius);
    ctx.arcTo(x, y, x + w, y, radius);
    ctx.closePath();
  }

  function create(canvas) {
    const ctx = canvas.getContext('2d');
    let current = layout(0, 0);

    function resize() {
      const host = canvas.parentElement;
      const width = host ? host.clientWidth : 0;
      const height = host ? host.clientHeight : 0;
      current = layout(width, height);

      const dpr = Math.max(1, finiteOr(root.devicePixelRatio, 1));
      canvas.width = Math.max(1, Math.round(current.totalW * dpr));
      canvas.height = Math.max(1, Math.round(current.totalH * dpr));
      canvas.style.width = current.totalW + 'px';
      canvas.style.height = current.totalH + 'px';
      ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
      return current;
    }

    // A single block with a lighter top-left bevel, which is what makes
    // the stack read as solid rather than flat.
    function block(x, y, size, color) {
      ctx.fillStyle = color;
      ctx.fillRect(x, y, size, size);
      ctx.fillStyle = 'rgba(255, 255, 255, 0.22)';
      ctx.fillRect(x, y, size, Math.max(1, size * 0.14));
      ctx.fillRect(x, y, Math.max(1, size * 0.14), size);
      ctx.fillStyle = 'rgba(0, 0, 0, 0.25)';
      ctx.fillRect(x, y + size - Math.max(1, size * 0.14), size, Math.max(1, size * 0.14));
      ctx.strokeStyle = 'rgba(0, 0, 0, 0.35)';
      ctx.lineWidth = 1;
      ctx.strokeRect(x + 0.5, y + 0.5, size - 1, size - 1);
    }

    function colorFor(type) {
      return Pieces.COLORS[type] || COLORS.garbage;
    }

    function drawWell(board) {
      const l = current;
      ctx.fillStyle = COLORS.panel;
      ctx.fillRect(l.boardX, l.pad, l.boardW, l.boardH);

      ctx.strokeStyle = COLORS.grid;
      ctx.lineWidth = 1;
      for (let c = 1; c < COLS; c++) {
        const x = l.boardX + c * l.cell + 0.5;
        ctx.beginPath();
        ctx.moveTo(x, l.pad);
        ctx.lineTo(x, l.pad + l.boardH);
        ctx.stroke();
      }
      for (let r = 1; r < VISIBLE_ROWS; r++) {
        const y = l.pad + r * l.cell + 0.5;
        ctx.beginPath();
        ctx.moveTo(l.boardX, y);
        ctx.lineTo(l.boardX + l.boardW, y);
        ctx.stroke();
      }

      const top = board.rows - board.visibleRows;
      for (let y = top; y < board.rows; y++) {
        for (let x = 0; x < board.cols; x++) {
          const type = board.grid[Board.index(board, x, y)];
          if (type === null) continue;
          block(l.boardX + x * l.cell, l.pad + (y - top) * l.cell, l.cell, colorFor(type));
        }
      }

      ctx.strokeStyle = COLORS.border;
      ctx.lineWidth = 2;
      ctx.strokeRect(l.boardX - 1, l.pad - 1, l.boardW + 2, l.boardH + 2);
    }

    function drawPiece(piece, y, ghost) {
      const l = current;
      const top = Board.ROWS - Board.VISIBLE_ROWS;
      const cells = Pieces.cells(piece.type, piece.state);
      for (let i = 0; i < cells.length; i++) {
        const cx = piece.x + cells[i].x;
        const cy = (y === null || y === undefined ? piece.y : y) + cells[i].y;
        const row = cy - top;
        if (row < 0 || row >= VISIBLE_ROWS) continue;   // still in the buffer
        const px = l.boardX + cx * l.cell;
        const py = l.pad + row * l.cell;
        if (ghost) {
          ctx.fillStyle = COLORS.ghost;
          ctx.fillRect(px + 1, py + 1, l.cell - 2, l.cell - 2);
          ctx.strokeStyle = colorFor(piece.type);
          ctx.lineWidth = 1;
          ctx.strokeRect(px + 1.5, py + 1.5, l.cell - 3, l.cell - 3);
        } else {
          block(px, py, l.cell, colorFor(piece.type));
        }
      }
    }

    // Draws a piece centred inside one of the side panels.
    function drawPreview(type, x, y, size) {
      const cells = Pieces.cells(type, '0');
      let minX = 99, maxX = -99, minY = 99, maxY = -99;
      for (let i = 0; i < cells.length; i++) {
        minX = Math.min(minX, cells[i].x);
        maxX = Math.max(maxX, cells[i].x);
        minY = Math.min(minY, cells[i].y);
        maxY = Math.max(maxY, cells[i].y);
      }
      const w = (maxX - minX + 1) * size;
      const h = (maxY - minY + 1) * size;
      const ox = x - w / 2;
      const oy = y - h / 2;
      for (let i = 0; i < cells.length; i++) {
        block(ox + (cells[i].x - minX) * size, oy + (cells[i].y - minY) * size, size, colorFor(type));
      }
    }

    function panelLabel(text, x, y) {
      ctx.fillStyle = COLORS.text;
      ctx.font = '600 11px ui-sans-serif, system-ui, sans-serif';
      ctx.textAlign = 'left';
      ctx.fillText(text, x, y);
    }

    function drawHold(game) {
      const l = current;
      panelLabel('HOLD', l.holdX, l.pad + 12);
      const boxY = l.pad + 20;
      const boxH = l.cell * 3;
      ctx.fillStyle = COLORS.panel;
      ctx.fillRect(l.holdX, boxY, l.panelW, boxH);
      if (game.hold) {
        const size = Math.max(4, Math.floor(l.cell * 0.72));
        ctx.globalAlpha = game.canHold ? 1 : 0.4;
        drawPreview(game.hold, l.holdX + l.panelW / 2, boxY + boxH / 2, size);
        ctx.globalAlpha = 1;
      }
    }

    function drawNext(game) {
      const l = current;
      panelLabel('NEXT', l.nextX, l.pad + 12);
      const size = Math.max(4, Math.floor(l.cell * 0.66));
      const slotH = l.cell * 2.6;
      for (let i = 0; i < game.queue.length; i++) {
        const boxY = l.pad + 20 + i * slotH;
        ctx.fillStyle = COLORS.panel;
        ctx.fillRect(l.nextX, boxY, l.panelW, slotH - 6);
        drawPreview(game.queue[i], l.nextX + l.panelW / 2, boxY + (slotH - 6) / 2, size);
      }
    }

    function draw(state) {
      const game = state.game;
      const l = current;

      ctx.fillStyle = COLORS.background;
      ctx.fillRect(0, 0, l.totalW, l.totalH);

      drawWell(game.board);
      if (game.piece) {
        const ghost = Game.ghostY(game);
        if (ghost !== null && ghost !== game.piece.y) drawPiece(game.piece, ghost, true);
        drawPiece(game.piece, game.piece.y, false);
      }
      drawHold(game);
      drawNext(game);
    }

    resize();

    return {
      resize: resize,
      draw: draw,
      get layout() { return current; }
    };
  }

  root.Renderer = {
    MIN_CELL: MIN_CELL,
    PAD: PAD,
    GAP: GAP,
    PANEL_CELLS: PANEL_CELLS,
    COLORS: COLORS,
    layout: layout,
    create: create
  };
})(typeof window !== 'undefined' ? window : globalThis);
```

- [ ] **Step 7: Create the game loop**

Create `main.js`. The frame delta is clamped twice over: `Game.tick` guards the engine, and pausing on blur means a backgrounded tab stops accumulating at all.

```js
(function (root) {
  'use strict';

  const canvas = document.getElementById('board');
  const renderer = Renderer.create(canvas);
  const settings = Input.loadSettings(root.localStorage);
  const input = Input.createState(settings);

  let game = null;
  let paused = false;
  let lastFrameMs = 0;
  const listeners = [];

  function softDropMsFor(handling) {
    return 1000 / Math.max(1, handling.softDropFactor);
  }

  function newGame(mode) {
    game = Game.create({
      mode: mode || 'marathon',
      seed: (Date.now() ^ Math.floor(Math.random() * 0xffff)) & 0xffffff,
      softDropMs: softDropMsFor(input.handling)
    });
    paused = false;
    lastFrameMs = 0;
    // A key held across the restart must not steer the new piece.
    Input.reset(input);
    emit([{ type: 'newgame', mode: game.mode }]);
    return game;
  }

  function emit(events) {
    if (events.length === 0) return;
    for (const listener of listeners) listener(events, game);
  }

  function setPaused(value) {
    if (paused === value) return;
    paused = value;
    Input.reset(input);
    emit([{ type: paused ? 'paused' : 'resumed' }]);
  }

  function frame(nowMs) {
    const dt = lastFrameMs === 0 ? 0 : nowMs - lastFrameMs;
    lastFrameMs = nowMs;

    const actions = Input.poll(input, paused ? 0 : dt);

    if (actions.retry) {
      newGame(game.mode);
    } else if (actions.pause && game.status === 'playing') {
      setPaused(!paused);
    }

    if (!paused && game.status === 'playing') {
      emit(Game.tick(game, dt, actions));
    }

    renderer.draw({ game: game, paused: paused });
    root.requestAnimationFrame(frame);
  }

  root.addEventListener('resize', function () { renderer.resize(); });

  // A backgrounded tab stops receiving frames, then hands over one huge
  // delta on return. Pausing on blur means there is nothing to catch up.
  root.addEventListener('blur', function () {
    if (game && game.status === 'playing') setPaused(true);
  });
  document.addEventListener('visibilitychange', function () {
    if (document.hidden && game && game.status === 'playing') setPaused(true);
  });

  Input.attach(input, root);
  renderer.resize();
  newGame('marathon');
  root.requestAnimationFrame(frame);

  root.App = {
    newGame: newGame,
    togglePause: function () { setPaused(!paused); },
    setPaused: setPaused,
    isPaused: function () { return paused; },
    getGame: function () { return game; },
    getInput: function () { return input; },
    getRenderer: function () { return renderer; },
```

```js
  // Effects are plain records aged by the frame delta. Keeping the ageing
  // separate from the drawing makes it testable without a canvas.
  function advanceEffects(effects, dtMs) {
    if (!effects || effects.length === 0) return [];
    const dt = Math.max(0, finiteOr(dtMs, 0));
    const alive = [];
    for (let i = 0; i < effects.length; i++) {
      const effect = effects[i];
      const aged = {};
      for (const key of Object.keys(effect)) aged[key] = effect[key];
      aged.ageMs = finiteOr(effect.ageMs, 0) + dt;
      if (aged.ageMs < finiteOr(effect.lifeMs, 0)) alive.push(aged);
    }
    return alive;
  }
```

```js
  function safeNumber(value) {
    const n = Number(value);
    return isFinite(n) && n > 0 ? n : 0;
  }

  function pad2(n) {
    return n < 10 ? '0' + n : String(n);
  }

  function formatTime(ms) {
    const total = safeNumber(ms);
    const minutes = Math.floor(total / 60000);
    const seconds = Math.floor((total % 60000) / 1000);
    const hundredths = Math.floor((total % 1000) / 10);
    return minutes + ':' + pad2(seconds) + '.' + pad2(hundredths);
  }
```

```js
(function (root) {
  'use strict';

  const KEY = 'tetris.bests.v1';
  const MODES = ['marathon', 'sprint'];

  function isRecord(value) {
    return value !== null && typeof value === 'object' && !Array.isArray(value);
  }

  function isBetter(mode, candidate, existing) {
    if (!isRecord(candidate)) return false;
    if (!isRecord(existing)) return true;
    if (mode === 'sprint') {
      return Number(candidate.timeMs) < Number(existing.timeMs);
    }
    return Number(candidate.score) > Number(existing.score);
  }

  function load(storage) {
    const empty = { marathon: null, sprint: null };
    if (!storage) return empty;

    let raw = null;
    try {
      raw = storage.getItem(KEY);
    } catch (err) {
      return empty;
    }
    if (!raw) return empty;

    let parsed = null;
    try {
      parsed = JSON.parse(raw);
    } catch (err) {
      return empty;
    }
    if (!isRecord(parsed)) return empty;

    const out = { marathon: null, sprint: null };
    for (const mode of MODES) {
      if (isRecord(parsed[mode])) out[mode] = parsed[mode];
    }
    return out;
  }

  function save(storage, bests) {
    if (!storage) return false;
    try {
      storage.setItem(KEY, JSON.stringify(bests));
      return true;
    } catch (err) {
      return false;
    }
  }

  function record(storage, mode, result) {
    const bests = load(storage);
    if (MODES.indexOf(mode) === -1) return { updated: false, best: null };

    if (isBetter(mode, result, bests[mode])) {
      bests[mode] = result;
      save(storage, bests);
      return { updated: true, best: result };
    }
    return { updated: false, best: bests[mode] };
  }

  root.Bests = {
    KEY: KEY,
    MODES: MODES,
    isBetter: isBetter,
    load: load,
    save: save,
    record: record
  };
})(typeof window !== 'undefined' ? window : globalThis);
```

```js
  'use strict';

  const SCREENS = ['menu', 'pause', 'over', 'settings'];

  // One row per action, in the order a player would look for them.

    const codes = [];

      if (bindings[code] === action) codes.push(code);

    return code

      .replace(/^Digit/, '')
      .replace(/^Arrow/, '')
      .replace(/^Shift(Left|Right)$/, 'Shift')
      .replace(/^Control(Left|Right)$/, 'Ctrl');

    const app = options.app;

      arrMs: { input: document.getElementById('set-arr'), output: document.getElementById('out-arr') },

    let capturing = null;   // the action waiting for a key

    function show(name) {
      currentName = name;

      if (name === 'menu') refreshBests();
      if (name === 'settings') refreshSettings();

      const bests = Bests.load(root.localStorage);

      event.preventDefault();
      event.stopPropagation();

      if (event.code !== 'Escape') {
        const input = app.getInput();
        const next = {};
        for (const code of Object.keys(input.bindings)) {
          if (input.bindings[code] !== capturing) next[code] = input.bindings[code];
        }
        next[event.code] = capturing;
        input.bindings = Input.sanitizeBindings(next);
        Input.saveSettings(root.localStorage, { bindings: input.bindings, handling: input.handling });
      }

      capturing = null;
      renderBindings();

      return function (event) {

      if (!action) return;

        options.onStartGame(action);
      } else if (action === 'guide') {

      } else if (action === 'settings') {
        show('settings');
      } else if (action === 'menu') {
        show('menu');
      } else if (action === 'resume') {

        app.setPaused(false);
      } else if (action === 'restart') {

      } else if (action === 'reset-settings') {
        const input = app.getInput();
        input.bindings = Input.sanitizeBindings(Input.DEFAULT_BINDINGS);
        input.handling = Input.sanitizeHandling(Input.DEFAULT_HANDLING);
        Input.saveSettings(root.localStorage, { bindings: input.bindings, handling: input.handling });
        app.applyHandling();
        refreshSettings();

    overlay.addEventListener('click', onClick);
    // Capture phase, so a rebinding press never reaches the game's own
    // key handler.
    root.addEventListener('keydown', onCaptureKey, true);

    return {
      show: show,
      hide: hide,
      current: function () { return currentName; },
      isCapturing: function () { return capturing !== null; }
    };
```

```js
(function (root) {
  'use strict';

  const canvas = document.getElementById('board');
  const renderer = Renderer.create(canvas);
  const hud = Hud.create(document.getElementById('stage'));
  const settings = Input.loadSettings(root.localStorage);
  const input = Input.createState(settings);

  let game = null;
  let paused = false;
  let lastFrameMs = 0;
  const listeners = [];

  function softDropMsFor(handling) {
    return 1000 / Math.max(1, handling.softDropFactor);
  }

  // Called when a settings slider moves, so the change lands on the game
  // already in progress rather than the next one.
  function applyHandling() {
    if (game) game.opts.softDropMs = softDropMsFor(input.handling);
  }

  function emit(events) {
    if (events.length === 0) return;
    for (const listener of listeners) listener(events, game);
  }

  function newGame(mode) {
    game = Game.create({
      mode: mode || 'marathon',
      seed: (Date.now() ^ Math.floor(Math.random() * 0xffff)) & 0xffffff,
      softDropMs: softDropMsFor(input.handling)
    });
    paused = false;
    lastFrameMs = 0;
    // A key held across the restart must not steer the new piece.
    Input.reset(input);
    emit([{ type: 'newgame', mode: game.mode }]);
    return game;
  }

  function setPaused(value) {
    if (paused === value) return;
    paused = value;
    Input.reset(input);
    emit([{ type: paused ? 'paused' : 'resumed' }]);
    if (paused) screens.show('pause');
    else screens.hide();
  }

  function showGameOver(event, result, isBest) {
    document.getElementById('over-title').textContent =
      event.type === 'win' ? 'Sprint complete' : 'Game over';
    document.getElementById('over-detail').textContent =
      event.type === 'win'
        ? Hud.formatTime(result.timeMs) + ' · ' + result.lines + ' lines'
        : result.score + ' points · ' + result.lines + ' lines';
    document.getElementById('over-best').hidden = !isBest;
    screens.show('over');
  }

  const screensOptions = {
    app: null,
    onStartGame: function (mode) { newGame(mode); },
    onOpenGuide: function () {
      // The guide arrives in a later task; until then the button is inert
      // rather than broken.
      if (root.SpinGuide) root.SpinGuide.open();
    }
  };
  const screens = Screens.create(screensOptions);

  function handleEvent(event) {
    if (event.type === 'harddrop' && event.cells > 0 && event.piece) {
      renderer.addTrail(event.piece, event.piece.y - event.cells, event.piece.y);
    }
    if (event.type === 'lock' && event.lines > 0) {
      renderer.addFlash(event.rows);
    }
    if (event.type === 'gameover' || event.type === 'win') {
      const result = {
        score: game.scoring.score,
        lines: game.scoring.lines,
        timeMs: game.timeMs
      };
      const outcome = Bests.record(root.localStorage, game.mode, result);
      showGameOver(event, result, outcome.updated);
    }
  }

  function frame(nowMs) {
    const dt = lastFrameMs === 0 ? 0 : nowMs - lastFrameMs;
    lastFrameMs = nowMs;

    const actions = Input.poll(input, paused ? 0 : dt);

    // Menus, settings, and the game-over screen swallow play input. The
    // pause screen is the exception: Esc there resumes.
    const screen = screens.current();
    if (screen !== null && screen !== 'pause') {
      renderer.draw({ game: game, paused: true, dtMs: dt });
      root.requestAnimationFrame(frame);
      return;
    }

    if (actions.retry) {
      newGame(game.mode);
    } else if (actions.pause && game.status === 'playing') {
      setPaused(!paused);
    }

    if (!paused && game.status === 'playing') {
      const events = Game.tick(game, dt, actions);
      for (let i = 0; i < events.length; i++) handleEvent(events[i]);
      emit(events);
    }

    hud.update(game);
    renderer.draw({ game: game, paused: paused, dtMs: dt });
    root.requestAnimationFrame(frame);
  }

  root.addEventListener('resize', function () { renderer.resize(); });

  // A backgrounded tab stops receiving frames, then hands over one huge
  // delta on return. Pausing means there is nothing to catch up on.
  root.addEventListener('blur', function () {
    if (game && game.status === 'playing' && screens.current() === null) setPaused(true);
  });
  document.addEventListener('visibilitychange', function () {
    if (document.hidden && game && game.status === 'playing' && screens.current() === null) {
      setPaused(true);
    }
  });

  root.App = {
    newGame: newGame,
    togglePause: function () { setPaused(!paused); },
    setPaused: setPaused,
    isPaused: function () { return paused; },
    applyHandling: applyHandling,
    getGame: function () { return game; },
    getInput: function () { return input; },
    getRenderer: function () { return renderer; },
    onEvents: function (handler) { listeners.push(handler); }
  };
  screensOptions.app = root.App;

  root.App.onEvents(function (events) { hud.apply(events); });

  Input.attach(input, root);
  renderer.resize();
  newGame('marathon');
  screens.show('menu');
  root.requestAnimationFrame(frame);
})(window);
```

Note the one ordering subtlety: `setPaused` refers to `screens`, which is
declared with `const` further down. That is safe because `setPaused` is only
ever *called* after module evaluation finishes, never during it.

```js
  function lessonById(id) {
    for (let i = 0; i < LESSONS.length; i++) {
      if (LESSONS[i].id === id) return LESSONS[i];
    }
    return null;
  }

  function collect(into, batch) {
    for (let i = 0; i < batch.length; i++) into.push(batch[i]);
  }

  function runStep(game, step, events) {
    if (step.until === 'grounded') {
      for (let i = 0; i < MAX_ITERATIONS && game.piece && !Game.isGrounded(game); i++) {
        collect(events, Game.tick(game, TICK_MS, { softDrop: true }));
      }
      return;
    }
    if (step.until === 'locked') {
      for (let i = 0; i < MAX_ITERATIONS; i++) {
        const batch = Game.tick(game, TICK_MS, {});
        collect(events, batch);
        let locked = false;
        for (let e = 0; e < batch.length; e++) {
          if (batch[e].type === 'lock') locked = true;
        }
        if (locked) return;
      }
      return;
    }

    const repeat = step.repeat || 1;
    const dt = step.dtMs || 0;
    for (let i = 0; i < repeat; i++) {
      collect(events, Game.tick(game, dt, step.actions || {}));
    }
  }

  // Replays the lesson from scratch every time. Stepping backwards in the
  // player is then just "run to step n - 1", which keeps the player free of
  // its own copy of game state.
  function runLesson(lesson, upToStep) {
    if (!lesson || lesson.reference) return null;

    const limit = (upToStep === undefined || upToStep === null)
      ? lesson.steps.length
      : Math.max(0, Math.min(upToStep, lesson.steps.length));

    const game = Game.create({
      board: lesson.rows.length ? Board.fromRows(lesson.rows) : Board.create(),
      pieces: lesson.pieces,
      seed: 1,
      lockDelayMs: 500
    });

    const events = [];
    const rotations = [];
    let stepsRun = 0;

    for (let i = 0; i < limit; i++) {
      const before = game.piece
        ? { type: game.piece.type, state: game.piece.state, x: game.piece.x, y: game.piece.y }
        : null;
      const stepEvents = [];
      runStep(game, lesson.steps[i], stepEvents);

      for (let e = 0; e < stepEvents.length; e++) {
        if (stepEvents[e].type === 'rotate' && before) {
          // A step could in principle rotate and then lock, leaving no
          // active piece to read the landing position from.
          const landed = game.piece || before;
          rotations.push({
            step: i,
            from: before,
            to: { type: landed.type, state: stepEvents[e].state, x: landed.x, y: landed.y },
            kickIndex: stepEvents[e].kickIndex
          });
        }
      }

      collect(events, stepEvents);
      stepsRun += 1;
    }

    return { game: game, events: events, rotations: rotations, stepsRun: stepsRun };
  }

  function create(elements) {
    const overlay = elements.overlay;
    const renderer = Renderer.create(elements.canvas);

    let lesson = LESSONS[0];
    let step = 0;
    let state = null;
    let playing = false;
    let speed = 1;
    let waitMs = 0;
    let rafId = null;
    let lastMs = 0;

    function rebuild() {
      state = runLesson(lesson, step);
      elements.caption.textContent = lesson.reference
        ? lesson.steps[0].caption
        : (step === 0 ? lesson.blurb : lesson.steps[step - 1].caption);
      elements.title.textContent = lesson.title;
      elements.progress.textContent = lesson.reference
        ? ''
        : step + ' / ' + lesson.steps.length;
      elements.reference.hidden = !lesson.reference;
      elements.canvas.hidden = lesson.reference === true;
    }

    function renderList() {
      elements.list.textContent = '';
      for (const entry of LESSONS) {
        const button = document.createElement('button');
        button.type = 'button';
        button.textContent = entry.title;
        button.className = entry.id === lesson.id ? 'active' : '';
        button.addEventListener('click', function () { select(entry.id); });
        elements.list.appendChild(button);
      }
    }

    function select(id) {
      const found = lessonById(id);
      if (!found) return;
      lesson = found;
      step = 0;
      playing = false;
      waitMs = 0;
      renderList();
      rebuild();
    }

    function stepForward() {
      if (lesson.reference || step >= lesson.steps.length) {
        playing = false;
        return;
      }
      step += 1;
      rebuild();
    }

    function stepBack() {
      if (lesson.reference || step === 0) return;
      step -= 1;
      playing = false;
      rebuild();
    }

    function replay() {
      step = 0;
      waitMs = 0;
      rebuild();
      playing = !lesson.reference;
    }

    function drawArrows() {
      if (!state || state.rotations.length === 0) return;
      const last = state.rotations[state.rotations.length - 1];
      if (last.step !== step - 1 || last.kickIndex === 0) return;
      elements.kick.textContent = 'kick offset ' + (last.kickIndex + 1) + ' of 5';
      elements.kick.hidden = false;
    }

    function frame(nowMs) {
      const dt = lastMs === 0 ? 0 : nowMs - lastMs;
      lastMs = nowMs;

      if (playing) {
        waitMs += dt;
        const holdMs = 900 / speed;
        if (waitMs >= holdMs) {
          waitMs = 0;
          stepForward();
        }
      }

      if (state && !lesson.reference) {
        elements.kick.hidden = true;
        renderer.draw({ game: state.game, paused: true, dtMs: dt });
        drawArrows();
      }
      rafId = root.requestAnimationFrame(frame);
    }

    function open() {
      overlay.hidden = false;
      renderer.resize();
      renderList();
      select(lesson.id);
      lastMs = 0;
      if (rafId === null) rafId = root.requestAnimationFrame(frame);
    }

    function close() {
      overlay.hidden = true;
      playing = false;
      if (rafId !== null) {
        root.cancelAnimationFrame(rafId);
        rafId = null;
      }
    }

    elements.play.addEventListener('click', function () { playing = !playing; waitMs = 0; });
    elements.next.addEventListener('click', function () { playing = false; stepForward(); });
    elements.prev.addEventListener('click', stepBack);
    elements.replayButton.addEventListener('click', replay);
    elements.close.addEventListener('click', close);
    elements.speed.addEventListener('change', function (event) {
      speed = Number(event.target.value) || 1;
    });

    return {
      open: open,
      close: close,
      select: select,
      play: function () { playing = true; },
      pause: function () { playing = false; },
      stepForward: stepForward,
      stepBack: stepBack,
      replay: replay,
      setSpeed: function (value) { speed = Number(value) || 1; }
    };
  }

  root.SpinGuide = {
    TICK_MS: TICK_MS,
    SPEEDS: SPEEDS,
    LESSONS: LESSONS,
    lessonById: lessonById,
    runLesson: runLesson,
    create: create
  };
})(typeof window !== 'undefined' ? window : globalThis);
```
